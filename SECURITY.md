# Security Policy

## Supported versions

Security fixes are applied to the current minor release line.

## Reporting

Report vulnerabilities privately to the repository maintainer. Do not publish API keys, access tokens, private prompts, customer scripts, or personal data in public issues.

## Operational controls

- Keep `.env` and provider credentials out of Git.
- Limit access to generated scripts and source material.
- Treat brief contents, URL metadata, and assets as untrusted data.
- Review factual, legal, commercial, and rights-sensitive claims before publication.
- Rotate exposed provider credentials immediately.
